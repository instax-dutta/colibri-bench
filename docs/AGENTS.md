# Docs - durable plans

## Purpose

- Owns durable benchmark plans and server/Colibri reference notes for this project.

## Ownership

- This folder owns `benchmark-plan.md` (server specs, Colibri supported models, benchmarkable list, serial download-benchmark-delete method) and `REPORT.md` (the final research report).
- Parent AGENTS.md owns project-wide workflow and safety rules.

## Local Contracts

- benchmark-plan.md is the single source of truth for which models fit the host and the benchmark order. Update it when specs, catalog sizes, or method change.
- Keep numbers sourced (Colibri setup_catalog.py / README, df/free checks). Do not invent tok/s.

## Work Guidance

- Before starting a model, check host processes and disk headroom. Ask before pausing or stopping anything heavy.
